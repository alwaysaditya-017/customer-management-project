# Customer Management System

Full-stack assessment project using Java Spring Boot + React + PostgreSQL.

## Stack
- Java 17
- Spring Boot 3.5
- Spring Web
- Spring Data JPA / Hibernate
- Jakarta Validation
- PostgreSQL
- React 19
- Vite
- Axios

## PostgreSQL

Create the database:

```sql
CREATE DATABASE customer_management;
```

Default backend connection:

```properties
spring.datasource.url=jdbc:postgresql://localhost:5432/customer_management
spring.datasource.username=postgres
spring.datasource.password=postgres
```

Change username/password in `backend/src/main/resources/application.properties` if needed.

The backend uses `spring.jpa.hibernate.ddl-auto=update`, so the `customers` table is created automatically. `data.sql` adds sample records.

## Run backend

Requirements: Java 17+, Maven 3.9+, PostgreSQL.

```bash
cd backend
mvn clean install
mvn spring-boot:run
```

API: `http://localhost:8080`

## Run frontend

Requirements: Node.js 18+.

```bash
cd frontend
npm install
npm run dev
```

UI: `http://localhost:5173`

Optional `frontend/.env`:

```properties
VITE_API_URL=http://localhost:8080/api
```

## REST APIs

| Method | Endpoint | Purpose |
|---|---|---|
| GET | `/api/customers` | List/search/paginate/sort |
| GET | `/api/customers/{id}` | View details |
| POST | `/api/customers` | Create |
| PUT | `/api/customers/{id}` | Update |
| DELETE | `/api/customers/{id}` | Delete |

Examples:

```text
GET /api/customers?search=john&page=0&size=10&sortBy=name&direction=asc
```

Create request:

```json
{
  "name": "Alice Johnson",
  "email": "alice@example.com",
  "phoneNumber": "+91 9876543210",
  "company": "Example Technologies",
  "status": "ACTIVE"
}
```

## HTTP statuses

- `200 OK` - GET/PUT
- `201 Created` - POST
- `204 No Content` - DELETE
- `400 Bad Request` - validation
- `404 Not Found` - missing customer
- `409 Conflict` - duplicate email/constraint
- `500 Internal Server Error` - unexpected error

## Assumptions

1. PostgreSQL runs on localhost:5432.
2. Database name is `customer_management`.
3. PostgreSQL credentials are configurable in `application.properties`.
4. Authentication/authorization is not included because it was not part of the supplied requirements.
5. Created Date is generated by the backend.
6. Email is unique.
7. Status is `ACTIVE` or `INACTIVE`.
